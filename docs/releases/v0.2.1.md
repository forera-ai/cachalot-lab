# Cachalot Studio 0.2.1

This backward-compatible patch fixes whole-Mac memory telemetry on macOS systems whose Mach VM response contains fewer fields than the current SDK structure. Studio reads the fields needed for active, wired, and compressed memory and continues to show unavailable data when sampling truly fails.

The Mac icon tests now use a fixture and the bundled app icon. They no longer assume the CI runner includes artwork for specific Mac models. All 0.2.0 features remain available.

## Requirements

- Apple Silicon Mac running macOS 14 or newer.
- A separately installed Cachalot Python environment and model checkpoint for managed runtimes. Studio does not install Python, Cachalot, model weights, or an updater.

## Compatibility and limits

- Cachalot 0.45.3 is the reviewed runtime source baseline. A native MiniMax 0.45.1 managed launch, short streamed reply, and clean stop were verified for 0.2.0. Other model families and sustained workloads were not validated in that smoke test.
- Studio connects only to loopback HTTP endpoints. API keys remain in memory and are not stored in launch profiles.
- After an abrupt app exit, Studio does not attach to or terminate a prior server. An occupied port blocks a new launch until it is cleared or a different port is selected.
