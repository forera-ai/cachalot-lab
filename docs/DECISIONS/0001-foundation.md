# ADR 0001: Initial foundation

Status: accepted for local development.

Use Tauri 2, React 19, strict TypeScript, Vite, Tailwind CSS v4, and a Rust-owned privileged core as specified in the product brief. Keep the runtime repository read-only from Lab. Keep design assets as editable vectors. Defer application dependencies and screen implementation until brand direction is selected so the design system can be built around an approved mark.
